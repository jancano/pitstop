# Security

Report a security issue in Pitstop privately using **Report a vulnerability** on the repository's Security tab. Include the affected commit or version, platform and steps to reproduce it. [Pitstop private advisories](https://github.com/jancano/pitstop/security/advisories/new)

The maintainer triages reports and coordinates disclosure through the advisory. Pitstop currently ships from source and has no automatic release workflow.
