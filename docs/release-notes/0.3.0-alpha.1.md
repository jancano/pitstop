# Pitstop 0.3.0-alpha.1

This candidate introduces Pitstop's native C and C++ project creation and editing workflow. The tested toolchain is Windows x64 with Xmake and Xrepo 3.1.2, LLVM-MinGW 23.1.6, libc++, clangd and clang-scan-deps.

## Changes

- The native welcome screen opens projects, folders and files, clones Git repositories, and lists recent projects.
- New Project reads bundled and local manifests. Seven Xmake templates cover C and C++ console applications, static and shared libraries, a module-only library, a multi-target application and an empty workspace. The wizard checks compiler capabilities, exposes compatible language standards and previews the files before writing them.
- Project Explorer groups evaluated sources and dependencies by target. Xmake project edits use a Lua preview when the evaluated source patterns do not already include the new file.
- Native Toolchains settings show discovered tools and accept executable overrides. Workspace trust applies before evaluation and native tooling starts.
- The Windows packages omit the managed language server, project host, debugger, and managed inspection, preview and test helpers. The editor, terminal, Git, clangd and existing native build, run and module workflows remain available.

## Installation

Install the reference toolchain separately. The per-user installer is `Pitstop-windows-x64.exe`. For a portable installation, extract `Pitstop-windows-x64-portable.zip` and run `Pitstop/Pitstop.exe`. Add a `pitstop-data` directory beside that executable to keep its state with the portable copy. Installed state stays in `%LOCALAPPDATA%\Pitstop`. The candidate uses manual installs and updates. [Windows setup and quick start](../../README.md#windows-setup)

## Verification and limitations

Locked restore and the solution build passed. Four focused tests and an installed-executable trust test passed. The installed and portable executables opened, edited, built and ran Hello Modules through MCP. Installer removal preserved existing user state. Compared with 0.2.0-alpha.1, the installer is 35.0% smaller and the portable ZIP is 36.4% smaller. [Native-first architecture and validation report](../architecture/native-first-ide.md)

Full inherited regression suites and the wider accessibility and display-scale review are still release checks. Native debugging, Xrepo package installation and CMake integration remain future work. Other platform and toolchain combinations and unsaved cross-module semantic propagation remain unverified.
